Plataforma de Eco-Mercado Digital | Flutter + Django | Hackathon Nicaragua 2026 - Categoría Aficionado

Plataforma móvil tipo marketplace diseñada para conectar compradores y vendedores de frutas y verduras frescas, optimizando el descubrimiento de productos de temporada. Proyecto desarrollado para Hackathon Nicaragua 2026 - Categoría Aficionado



Stack:

Frontend (Aplicación Móvil): Flutter

Backend & API: Django + Django Rest Framework (Python)

Base de datos: PostgreSQL
